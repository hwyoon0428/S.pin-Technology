# 자가개선 절차 도입

- 날짜: 2026-11-16
- 문제와 근거: 저장소에 개선을 반복하고 결과를 확인하는 절차가 없었다. 저장소에는 초기 문서만 있고 실행·테스트 방법은 정의되지 않았다.
- 변경 전 기준선: 자가개선 절차와 결과 기록 양식이 없었다.
- 완료 조건: Codex에서 실행할 요청, 후보 선택, 검증, 결과 기록 및 다음 실행의 재검토 절차를 제공한다.
- 변경 내용: 절차와 기록 양식, 설계 결정을 추가하고 README와 에이전트 지침에서 연결했다.
- 검증 명령 또는 확인 방법과 결과: `git diff --check` 및 문서 링크와 파일 내용 확인.
- 미실행 검증과 이유: 애플리케이션 테스트와 자동 실행 검증은 해당 기능과 테스트 체계가 없어 수행하지 않았다.
- 결과 및 남은 위험: 수동 요청으로 반복할 수 있는 절차를 마련했다. 실제 향후 실행의 품질과 개선 효과는 아직 측정하지 않았다.
- 후속 후보: 프로젝트의 목적과 테스트가 정해지면 실제 실패 사례를 기준선으로 삼아 평가한다.
